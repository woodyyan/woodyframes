# Woody's Frames

一个用于展示和整理摄影作品的个人网站原型，以人像、风景、街头和人文四类为起点。视觉采用暖白底色、克制排版和完整画幅的大图观看体验。

> **当前是静态交互原型，不是已经接入对象存储的正式摄影网站。** 页面中的 12 张图片来自 Pexels，均为授权示例，不是 Woody 的作品。照片作者、原作链接和许可见 [`designs/woody-frames/assets/photos.json`](designs/woody-frames/assets/photos.json) 及页面内的「素材署名」。正式公开自己的作品前，请替换示例图片与文案，并核实人像公开展示的授权与隐私要求。

## 预览

无构建步骤、无运行时依赖。进入仓库根目录，运行一个本地 HTTP 服务：

```bash
python3 -m http.server 4311 --bind 127.0.0.1 --directory designs
```

然后打开 <http://127.0.0.1:4311/woody-frames/index.html>。可体验四类筛选、画廊/联系表切换、大图、暗场模式、键盘左右键、Esc 关闭和手机触屏左右滑动。右下角「原型说明 / 实现方案」包含详细设计及存储建议。

## 目录

```text
designs/woody-frames/
  index.html                网站原型入口（静态 HTML / CSS / JavaScript）
  assets/photos.json        示例照片元数据、摄影者、原作及许可链接
  assets/web/*.jpg          页面使用的展示尺寸照片
```

原始示例下载、测试截图、离线分享文件和本地工作记忆保留在本机，但通过 `.gitignore` 排除，不随源码上传。

## 部署到 Vercel

当前原型可以作为静态站部署：导入此仓库，把 **Root Directory** 设置为 `designs/woody-frames`，选择静态站点/其他框架预设，不填写构建命令，入口为 `index.html`。上线前先替换授权示例；目前没有连接云存储、域名或 Vercel 项目，也没有执行部署。

正式版计划使用 **Astro 静态构建 + Vercel**，源码只保存页面与照片索引；公开的压缩展示图放在对象存储，通过图片 CDN 提供。Cloudflare R2 + 自定义域名是面向全球访问的优先候选；若已有腾讯云资源或主要面向中国内地访客，则评估 COS + CDN，并实测两条访问链路。原片和未公开照片另存私有空间并独立备份。网站运行时不需要数据库或登录服务。

### 更新照片的预期流程

1. 在本地选片，导出不同尺寸的 sRGB 展示图，删除不必要的定位与 EXIF 信息。
2. 只将准备公开的展示图上传到对象存储，不把上传密钥放进仓库或浏览器。
3. 更新照片索引中的唯一 ID、标题、分类、尺寸、排序及对象键；校验对象存在后重新构建与发布静态站点。

这套上传和构建流程**尚未实现**。现有 `assets/photos.json` 是原型素材清单，不是云存储配置或在线管理后台。新增照片不会仅靠上传对象自动出现在网站上；需要更新索引并重新部署。若未来要在网页内上传或管理照片，需要单独设计有鉴权的管理能力。
